### Мой фокус
Сейчас я развиваюсь в направлении анализа данных и хочу исследовать задачи, связанные с поиском закономерностей в данных, проверкой гипотез и построением понятных аналитических выводов.
Мне интересны задачи, где анализ данных сочетается с созданием прикладных инструментов: дашбордов, автоматизированных отчётов, Telegram-ботов и сервисов для сбора и обработки данных.

Мне интересны следующие направления:
- Исследовательский анализ данных
- Продуктовая и бизнес-аналитика
- A/B-тестирование и проверка гипотез
- Анализ пользовательского поведения
- Визуализация данных и построение дашбордов
- Работа с SQL, Python и аналитическими инструментами.
