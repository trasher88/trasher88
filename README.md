## 📱Опубликованные Android-приложения в RuStore
**Разрабатываю самостоятельные пользовательские продукты, доступные в магазине приложений.** Работы включают развитие функциональности, UX, тестирование, подготовку релизов и интеграцию с экосистемой RuStore.

### [Субъекты РФ](https://www.rustore.ru/catalog/app/ru.trasher.regions)
Географический справочник по Субъектам и городам РФ: территориальные и демографические сведения, символика, автомобильные коды и часовые пояса.

**Инженерный фокус:** структурирование предметных данных, справочный UX, автономный доступ к информации, сопровождение опубликованного приложения.

### [Викторина по Субъектам РФ](https://www.rustore.ru/catalog/app/ru.trasher.regionquiz)
Образовательное приложение для изучения географии РФ: административные центры, флаги, гербы, автомобильные коды и расположение регионов на карте. Игровые режимы, фиксация прогресса. **Отдельное направление развития — обновлённый интерфейс, интерактивная карта и персонализированные сценарии обучения**.

**Инженерный фокус:** Android, образовательные сценарии, геоданные, управление состоянием интерфейса, функциональное тестирование.

### [Домашний архив](https://www.rustore.ru/catalog/app/ru.trasher88.homearchive)
Офлайн-ориентированное приложение для учёта имущества, чеков, документов и гарантийных сроков. Поиск, категории, напоминания, резервное копирование. Реализована модель **Free / PRO** с покупкой и восстановлением расширенных возможностей через RuStore.

**Инженерный фокус:** локальное хранение данных, работа с вложениями, защита пользовательской информации, жизненный цикл данных, монетизация.

### ⚙️Production-интеграция RuStore
Для данных приложений развёрнут **единый backend обработки событий магазина**: callback-endpoints, проверка и расшифровка сообщений, дедупликация, журнал событий в SQLite, HTTPS и Telegram-уведомления о покупках и возвратах.
**Стек:** Python, FastAPI, SQLite, Linux, systemd, Caddy, HTTPS, Cloudflare Worker, RuStore API / callbacks.

## 🔒Закрытые инженерные разработки
Часть проектов не представлена публичными репозиториями. Ниже - только функциональное назначение и общие инженерные подходы; **исходный код, внутренние компоненты и данные не публикуются**.

### Offline Document Search Engine - локальный поисковый движок
Разработка поискового компонента для автономной работы с документами формата PDF. Совмещение **полнотекстового и семантического поиска**, ранжирование результатов и интеграция в Android-приложение без зависимости от облачных сервисов.

**Инженерный фокус:** подготовка и индексация документов, качество релевантности, ограниченные ресурсы мобильного устройства, модульность и воспроизводимые проверки результатов поиска.

### Modular GIS Toolkit - библиотека геопространственных инструментов
Разработка используемых модулей для Android-приложений с интерактивной картой: работа с координатами, измерение расстояний, построение графических объектов, управление геометрией на карте и т.д.

**Инженерные задачи:** разделение вычислительного ядра и UI, переносимость между приложениями, автономные вычисления и тестирование интеграции на реальном Android-устройстве.
